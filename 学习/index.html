HTML 标签图解学习

把 HTML 文档结构和常用标签画成卡片，新手可以一眼看清“写法、作用、显示效果”。

一、HTML 文档基础结构

这一部分解释一个 HTML 文件从外到内的基本组成。

HTML文档声明标签

作用声明当前文档使用 HTML5 标准，让浏览器用现代网页规则解析页面。

位置必须写在 HTML 文件的最前面。

              <!DOCTYPE html>
<html lang="zh-CN">

作用HTML 文档的根元素，页面里的所有内容都放在它里面。

lang表示页面语言，zh-CN 代表中文（中国）。

              <html lang="zh-CN">
              <head></head>
              <body></body>
              </html>
<head>

作用存放给浏览器和搜索引擎看的信息，通常不会直接显示在网页正文里。

                <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">
                <title>网页标题</title>
                <link rel="stylesheet" href="style.css">
                <style>页面内部样式</style>
                <script src="app.js"></script>
                </head>

<meta> 元信息类

分类原因这些标签都是 <meta>，只是属性参数不同，所以归为一类。

常见参数charsetnamecontenthttp-equiv

用途声明字符编码、移动端视口、页面描述、关键词、兼容模式等元信息。

                      <meta charset="UTF-8">
                      <meta name="viewport" content="width=device-width, initial-scale=1.0">
                      <meta name="description" content="网页描述内容">
                      <meta name="keywords" content="关键词1, 关键词2">
                      <meta http-equiv="X-UA-Compatible" content="IE=edge">

<title>

作用定义浏览器标签页上显示的网页标题。

特点一个页面通常只写一个 <title>。

                      <title>学习网站</title>

<link>

作用引入外部资源，最常见的是外部 CSS 文件和网站图标。

常见属性relhref

                      <link rel="stylesheet" href="style.css">
                      <link rel="icon" href="favicon.ico">

<style>

作用在当前 HTML 文件内部直接编写 CSS 样式。

特点适合当前页面专用样式，多个页面共用样式更推荐外部 CSS。

                      <style>
                      body {
                      background: #f4f7fb;
                      }
                      </style>

<script>

作用引入或编写 JavaScript，让页面具有交互能力。

说明可以写在 <head> 中，也常写在 <body> 结束前。

                      <script src="app.js"></script>

<base>

作用设置页面中相对链接的默认基础地址。

特点一个文档中最多使用一个，通常不常用。

                      <base href="https://example.com/" target="_blank">

<noscript>

作用当浏览器不支持或禁用 JavaScript 时，提供备用提示。

说明可以放在 <head> 或 <body> 中。

                      <noscript>请启用 JavaScript 以获得完整功能。</noscript>
<body>

作用存放用户能在浏览器窗口中看到的页面内容。

内容分类文本内容媒体内容链接导航列表表格表单输入页面布局脚本交互

                <body>
                <!-- 文本内容类 -->
                <!-- 媒体内容类 -->
                <!-- 链接导航类 -->
                <!-- 列表表格类 -->
                <!-- 表单输入类 -->
                <!-- 页面布局类 -->
                <!-- 脚本交互类 -->
                </body>
                
          <!DOCTYPE html>
          <html lang="zh-CN">
          <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">
          <title>网页标题</title>
          </head>
          <body>
          用户能看到的内容写在这里
          </body>
          </html>

二、标题标签：<h1> 到 <h6>

<h1>、<h2>、<h3>、<h4>、<h5>、<h6>

作用定义页面标题和小标题，帮助读者理解内容层级。

层级<h1>最大、最重要，通常一个页面只写一个；<h2>到<h6>用于更细的子标题。

SEO合理的标题层级能帮助搜索引擎理解页面结构。

<h1>这是一个主标题</h1>
              <h2>这是一个副标题</h2>
              <h3>这是一个三级标题</h3>
              <h4>这是一个四级标题</h4>
              <h5>这是一个五级标题</h5>
              <h6>这是一个六级标题</h6>

这是一个主标题

这是一个副标题

这是一个三级标题

这是一个四级标题

这是一个五级标题
这是一个六级标题

三、段落标签：<p>

<p>

作用定义一段文字内容，让文本按段落显示。

特点每个段落应该放在单独的<p>标签中，浏览器会自动在段落前后留出间距。

<p>这是第一段文字。</p>
              <p>这是第二段文字。</p>

这是第一段文字。它用来表达一个完整的小主题。

这是第二段文字。另起一段后，内容层次会更清楚。

四、文本格式化标签

文本格式化标签可以分为两类：语义化标签和非语义化标签。

语义化标签不仅改变显示效果，还告诉浏览器、搜索引擎和辅助设备“这段文字有什么含义”。

1. 语义化标签

<strong>

作用表示重要内容，浏览器通常显示为加粗。

示例<strong>重要文本</strong>

重要文本：这是重要文本。

<em>

作用表示需要强调的内容，浏览器通常显示为倾斜。

示例<em>强调文本</em>

强调文本：这是强调文本。

<del>

作用表示已经删除或不再适用的内容，浏览器通常显示删除线。

示例<del>旧内容</del>

删除内容：这是旧内容。

<ins>

作用表示新插入或新增的内容，浏览器通常显示下划线。

示例<ins>新内容</ins>

新增内容：这是新内容。

<mark>

作用表示被标记或高亮的重点内容。

示例<mark>重点内容</mark>

高亮内容：这是重点内容。

<code>

作用表示一小段计算机代码。

示例<code>color: red;</code>

代码文本：color: red;
非语义化标签主要改变文字外观，本身不强调文字含义。

2. 非语义化标签

<b>

作用让文字视觉上加粗，但不表示“重要”。

示例<b>加粗文本</b>

加粗效果：这是加粗文本。

<i>

作用让文字视觉上倾斜，但不表示“强调”。

示例<i>倾斜文本</i>

倾斜效果：这是倾斜文本。

<u>

作用给文字添加下划线效果。

示例<u>下划线文本</u>

下划线效果：这是下划线文本。

<small>

作用让文字显示得更小。

示例<small>小号文本</small>

小号效果：这是小号文本。

<sub>

作用显示下标文本，常用于化学式。

示例H<sub>2</sub>O

下标效果：H2O

<sup>

作用显示上标文本，常用于指数或脚注。

示例x<sup>2</sup>

上标效果：x2
推荐记忆：如果文字有“重要、强调、删除、新增、高亮、代码”等含义，优先用语义化标签；如果只是想改变外观，再考虑非语义化标签。

五、块级元素和内联元素

块级元素

特点默认独占一行，通常用来搭建页面的大结构。

常见标签<div><p><h1><ul><li><section>

<div> 块级元素：我会占一整行
<p> 块级元素：我也会另起一行

内联元素

特点默认不会独占一行，会跟文字或其他内联元素排在同一行。

常见标签<span><a><strong><em><img><br>

普通文字 <span> 内联元素 <strong> 内联元素 仍然在同一行。
简单记忆：块级元素像“盒子”，常用于分区和排版；内联元素像“文字片段”，常用于修饰一小段内容。
